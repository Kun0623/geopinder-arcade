# GeoPinder Arcade 홍보 패키지

> 제작일: 2026-10-27  
> 공식 게임: https://geopinder-arcade.vercel.app/

## 1. 한 줄 소개

**지구본을 돌리고, 랜드마크를 찍고, 친구보다 정확하게 맞혀보세요.**

## 2. 공식 제품 설명

GeoPinder Arcade는 90년대 오락실 감성으로 즐기는 웹 기반 3D 지리 퀴즈 게임입니다. 사진과 힌트를 보고 3D 지구본에서 랜드마크의 위치를 선택하면 실제 위치와의 거리를 기준으로 점수가 계산됩니다. 초급·중급·고급 난이도, 1인 플레이, 2인 실시간 대결, 글로벌 랭킹을 지원하며 별도 설치 없이 브라우저에서 바로 플레이할 수 있습니다.

## 3. 핵심 메시지

### 메인 메시지
- **세계 지리를 외우는 게임이 아니라, 감으로 맞히고 점수로 증명하는 게임**
- **3D 지구본 위에서 펼쳐지는 레트로 아케이드 지리 퀴즈**
- **혼자 기록을 세우거나, 친구와 2P 대결로 승부하세요**

### 기능 메시지
- 3D 지구본에서 직접 위치 선택
- 실제 위치와의 거리에 따른 점수 계산
- 초급: 시간 제한 없음
- 중급: 20초 제한
- 고급: 10초 제한
- 1P 솔로 플레이
- 2P 실시간 대결 및 재대결
- 글로벌 랭킹
- 모바일·데스크톱 브라우저 지원
- 사용자가 새로운 문제와 사진을 제보할 수 있는 커뮤니티 기능

### 감성 메시지
- CRT 스캔라인, 네온 컬러, 픽셀 폰트로 재현한 90년대 오락실 분위기
- “이 랜드마크가 어디였더라?” 하는 기억과 직감의 한판 승부
- 짧게 한 판 하고, 점수는 계속 도전하게 만드는 구조

## 4. 주요 타깃

1. 지리·세계 랜드마크 퀴즈를 좋아하는 10~40대
2. GeoGuessr류 위치 추측 게임을 가볍게 즐기고 싶은 사용자
3. 친구와 즉석에서 경쟁할 수 있는 웹게임을 찾는 사용자
4. 여행·지도·역사·도시 콘텐츠에 관심 있는 사용자
5. 수업이나 동아리에서 가벼운 지리 활동을 찾는 교육·커뮤니티 운영자
