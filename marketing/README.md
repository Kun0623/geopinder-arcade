## 게시 순서

1. 게시할 채널의 규칙과 자기홍보 허용 여부를 먼저 확인합니다.
2. `social-posts.md`에서 채널에 맞는 초안을 선택합니다.
3. 해당 채널의 UTM 링크를 사용합니다.
4. 가능하면 `og-image.png` 또는 실제 플레이 화면을 첨부합니다.
5. 게시 후 24시간과 7일 시점에 클릭·게임 시작·게임 완료를 기록합니다.

## 추천 첫 게시물

초기에는 다음 순서가 가장 안전합니다.

1. X 또는 Threads에 짧은 런칭 게시물 A 게시
2. Instagram/Facebook에 게임 플레이 캡션과 대표 이미지 게시
3. 네이버 블로그에 게임 방법과 제작 배경 게시
4. 실제 피드백 3~5개를 반영한 뒤 Reddit·Product Hunt용 영문 소개 게시

## 자산 사용

이미지 자산은 프로젝트에 이미 포함된 파일을 재활용합니다. 외부 랜드마크 사진을 새로 홍보물에 넣을 경우에는 게임 데이터의 Wikimedia Commons attribution과 동일하게 저작자·라이선스를 확인해야 합니다.

## 주의사항

- 같은 문구를 여러 커뮤니티에 동시에 복사 게시하지 않습니다.
- 게임에 없는 기능이나 보장되지 않은 성능을 광고하지 않습니다.
- 광고·후원보다 게임 플레이 가치를 먼저 설명합니다.
- 제보 테스트 데이터나 개인 정보가 포함된 화면을 홍보 이미지로 사용하지 않습니다.
