# GeoPinder Arcade 홍보 영상 대본

공식 링크: https://geopinder-arcade.vercel.app/

## 30초 세로형 숏폼

### 목적
첫 3초 안에 게임 방식을 이해시키고, 마지막에 즉시 플레이를 유도합니다.

### 화면 구성과 내레이션

| 시간 | 화면 | 자막 / 내레이션 |
|---|---|---|
| 0–3초 | 네온 지구본과 랜드마크 사진을 빠르게 교차 편집 | “이 랜드마크, 어디 있는지 아세요?” |
| 3–7초 | 사진·힌트가 보이는 문제 화면 | “사진과 힌트를 보고…” |
| 7–12초 | 지구본을 돌리고 위치를 터치하는 장면 | “3D 지구본에 위치를 찍어보세요.” |
| 12–16초 | 실제 위치와 추측 핀, 거리·점수 표시 | “실제 위치에 가까울수록 높은 점수!” |
| 16–20초 | 초급·중급·고급 버튼과 타이머 장면 | “천천히 할 수도, 10초 안에 도전할 수도 있습니다.” |
| 20–25초 | 2P 대결 화면과 점수 비교 | “친구와 2P 대결도 가능.” |
| 25–30초 | 로고, 최고 점수, URL | “GeoPinder Arcade. 지금 한 판 시작하세요.” |

### 게시용 마지막 자막

`설치 없이 바로 플레이`  
`geopinder-arcade.vercel.app`

## 60초 가로형 소개 영상

### 대본

“지도와 퀴즈를 좋아한다면 GeoPinder Arcade를 플레이해보세요.

게임은 간단합니다. 랜드마크 사진과 힌트를 확인하고, 3D 지구본에서 실제 위치라고 생각하는 곳을 선택합니다. 정답에 가까울수록 더 높은 점수를 얻습니다.

초급에서는 시간 제한 없이 생각할 수 있고, 중급은 20초, 고급은 10초 안에 위치를 찾아야 합니다.

혼자 최고 점수에 도전하거나, 2P 대결에서 친구와 바로 승부할 수도 있습니다. 게임이 끝나면 랭킹에 기록을 남겨 다음 기록에 도전해보세요.

네온 컬러와 CRT 스캔라인으로 꾸민 90년대 오락실 감성의 3D 지리 퀴즈.

GeoPinder Arcade. 지구본을 돌리고, 랜드마크를 찾고, 점수를 올려보세요.

별도 설치 없이 지금 브라우저에서 플레이할 수 있습니다.”

## 촬영·편집 가이드

- 첫 장면은 반드시 지구본 또는 랜드마크 사진으로 시작합니다.
- 0–3초에 설명보다 질문을 먼저 보여줍니다.
- 실제 게임 조작 화면을 최소 2개 이상 포함합니다.
- 모바일 숏폼은 9:16, 1080×1920 권장.
- 가로형 소개 영상은 16:9, 1920×1080 권장.
- 배경음은 빠른 8비트 또는 신스웨이브 계열로 설정합니다.
- 작은 화면에서도 읽히도록 자막은 짧은 문장으로 유지합니다.
- 게임 화면을 과도하게 확대해 텍스처가 흐려 보이지 않도록 원본 비율을 유지합니다.

## 무료 제작용 편집 순서

1. 기존 `mobile-375x812.png` 또는 실제 플레이 녹화로 시작 화면을 보여줍니다.
2. 모바일 브라우저에서 게임을 플레이하며 3~5초 단위 클립을 녹화합니다.
3. 문제 사진 → 지구본 선택 → 점수 결과 순서로 편집합니다.
4. 마지막 3초에 공식 URL만 크게 표시합니다.
5. 게시 전 모바일에서 자막과 URL이 잘 읽히는지 확인합니다.
